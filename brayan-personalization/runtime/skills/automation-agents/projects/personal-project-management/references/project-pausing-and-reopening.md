# Project pausing and reopening

Canonical vault workflow: `~/personal-vault/_meta/workflows/projects/project-pausing-and-reopening-workflow.md`.

## Pause

Pause requires explicit evidence. Required README fields: `paused`, `pause_reason`, `resume_condition`, and `next_review` or `null` policy. Move from dashboard to backlog.

## Resume

Resume a paused project in place only if the objective is still valid, there is a concrete next action, stop condition is still valid/updated, and the workspace exists or is recreated.

## Reopen closed projects

Closed projects normally become a new slug/version. Reopen same slug only with explicit objective/success/stop/next-action decision and link the previous closeout.
