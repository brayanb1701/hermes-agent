# Watch-monitoring mode

Use for broad career pages, future cycles, generic portals, and high-interest organizations without a current specific application target.

Also use for high-interest future-cycle jobs/internships/fellowships when the near-term need is to plan a path toward competitiveness rather than draft application materials now. In those cases preserve the real `opportunity_kind` such as `internship`, keep `cv_relevance: strategic`, and produce a roadmap that later triggers `cv-tailoring` once target groups/roles and proof-of-work evidence are clearer.

Primary outputs in `preparation-packet.md` when selected:
- watch target summary
- relevant roles/programmes shortlist
- research path / role / faculty / group map when applicable
- proof-of-work project roadmap when competitiveness depends on future evidence
- trigger conditions for future action
- preparation gaps
- suggested reminders/check dates
- decision needed before promotion to a more active workflow mode such as `cv-tailoring`

Most watch records should stay `researched` until a specific target is chosen. Use `preparation-ready` for watch-monitoring only when Brayan explicitly wants a review/planning packet for that watch target.
